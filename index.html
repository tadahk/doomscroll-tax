doomscroll tax

the longer you scroll a feed, the slower the page scrolls. close the tab and it resets.

the first minute is free. then it slows: half speed at 3 minutes, a fifth at 9. works on x, reddit, facebook, instagram, linkedin, threads, bluesky, tumblr, pinterest, youtube and hn. the icon turns it off, or off for a site.

download for chrome

install

  1. unzip doomscroll-tax-chrome.zip
  2. open chrome://extensions (chrome, brave, edge, arc, dia, vivaldi)
  3. turn on developer mode, top right
  4. click load unpacked and pick the unzipped folder

chrome web store and firefox add-ons listings are in review.
