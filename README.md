# doomscroll tax (thanks claude)

the longer you scroll a feed, the slower the page scrolls. close the tab and it resets.

the first minute is free, then it slows: half speed at 3 minutes, a fifth at 9. works on x, reddit, facebook, instagram, linkedin, threads, bluesky, tumblr, pinterest, youtube and hn. the icon turns it off, or off for a site. nothing leaves your browser.

get it: https://tadahk.github.io/doomscroll-tax/

build: `node build.js` · tests: `node tests/test.js`
